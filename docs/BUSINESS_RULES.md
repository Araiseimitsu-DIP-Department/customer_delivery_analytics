# 確認できる業務仕様

業務承認済み仕様を推測して追加しない。以下は現在の実装が行う処理。

- 期間は開始・終了の両方が必要。SQL は両端を含む日付 BETWEEN。
- 顧客名は空白除去後の完全一致で製品マスタを引き、対応品番で納品を検索する。
- 品番は ILIKE による部分一致。顧客条件なしでは全顧客を対象とする。
- 顧客対応付けがない明細は「（未設定）」。数量・金額は数値変換できない値を 0 にする。
- 一覧は顧客別、品番別、顧客×品番別。列は顧客、品番、年、月、納品数、金額。
- 年次・月次合計は検索で取得した明細を集計する。
- 回帰予測は NumPy の最小二乗を使用。重み付き回帰は直近年を重視する。
- 外部要因予測は利用できる IIP / CI を使用。外部公開ファイルの将来形式は保証できない。
- 初期画面では DB に接続せず、顧客・品番候補は必要時に取得する。
- Excel はユーザー指定先へ保存し、一覧や予測結果・グラフを出力する。
